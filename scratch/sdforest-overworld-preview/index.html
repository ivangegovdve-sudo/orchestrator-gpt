02 / field notes

The forest is a doorway, not a disguise.

The scene is an authored orientation layer: genuine terrain, PBR materials, bioluminescent markers, and a portal shader. The catalogue stays ordinary HTML so the work remains reachable when motion, GPU, or bandwidth are unavailable.

01 / terrain

Real ground, real depth.

A dense Three.js mesh is displaced with a Poly Haven forest-ground material and a loaded rock GLTF, then placed inside exponential fog.

02 / markers

Light means a doorway.

Each project is a point-sprite shader plus a live 3D beacon. Hover, focus, click, drag, and scroll all resolve into the same selection model.

03 / entry

Pass through, then read.

The entry veil borrows the measured pass-through timing grammar of aengel.io, while the work itself remains SD Forest’s own content and brand.

03 / the rule of the forest

A catalogue should tell the truth before it tells a story.

The public set is mapped from measured routes. Chloé is named as row 00 because it matters to the ecosystem, but its internal route is not guessed or exposed. Every other row is a real public doorway from the local mapping note.
