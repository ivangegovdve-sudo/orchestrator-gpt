# Kids' Library design references

`approved-combination.png` is the static design approved for the interactive
preview. It combines the three-tree mark from Library Journal, the theme row
from Story Club, and the colors and illustrated forest banner from Story Garden.
The three earlier directions are retained in `concepts/`; `concept-brief.md`
records the exploration at that stage.

`source-art/` contains the original generated artwork used to produce the
optimized images in the preview. Each film has its own scene, while the figures
share a similar arrangement. These are independent images, not crops of the
approved page screenshot.

The preview contains the 63-title catalog with title/year/director/studio fields
fed from the per-title Iris verification ledger in `src/researchVerification.js`.
The former Cool Kids Animation Filmography is a candidate seed only; premise,
audience, age, content, and visual-style fields remain unverified unless marked
as editorial sample guidance. It does not yet contain a curated books collection.
