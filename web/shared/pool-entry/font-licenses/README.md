# Pool entry fonts

The self-hosted Latin font files under the six pool directories were reused
from PR #694, commit `2d19c23c6a653094315ad97e25a720f4fe7c31e1`.
That implementation sourced the subsets from Fontsource. Each font is licensed
under the SIL Open Font License 1.1. The upstream copyright notices and complete
licenses are preserved beside this file, retrieved from Google Fonts' source
repository on 2026-10-03.

| Pool | Font families | Upstream license directories |
|---|---|---|
| AI-d kit | Barlow Condensed; JetBrains Mono | `ofl/barlowcondensed`; `ofl/jetbrainsmono` |
| Artificial Self | Instrument Serif; IBM Plex Mono | `ofl/instrumentserif`; `ofl/ibmplexmono` |
| Design Gallery | Instrument Serif; Hanken Grotesk | `ofl/instrumentserif`; `ofl/hankengrotesk` |
| GrowingApp | Fraunces; Nunito Sans | `ofl/fraunces`; `ofl/nunitosans` |
| TinkerBox | Zilla Slab; Public Sans | `ofl/zillaslab`; `ofl/publicsans` |

Source: <https://github.com/google/fonts/tree/main/ofl>.
My Story continues to use the site's existing Alegreya families.
