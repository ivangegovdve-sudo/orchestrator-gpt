TinyLM Glass Box

A public glass-box experiment for tiny model councils. This SD Forest route tries to embed the current live console when the target allows framing and falls back to a direct launch when it does not.

Mode

Public glass-box first. Private-run mode stays a later build, and this page says so plainly.

Runtime

The live target is configurable so we can switch among local, Chloe/KVM2, and public hosts without changing the route.

Safety

This release is route-only. It does not alter the Forest HUB homepage until the direct route proves stable.
