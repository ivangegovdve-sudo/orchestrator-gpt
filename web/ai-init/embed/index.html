Embeddable AI_INIT Search

This page uses a separate search bar wired to the shared glossary database. Click any result to copy formatted text.

Example integration: <script src="/web/ai-init/glossary-data.js"></script> <script src="/web/ai-init/glossary-search.js"></script> <script> AIInitGlossary.mountSearch({ input: '#my-search', resultsContainer: '#my-results', limit: 30, onCopy: (entry, ok) => console.log('copied', entry.abbr, ok) }); </script>
