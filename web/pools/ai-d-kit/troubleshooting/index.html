Runtime notes

Public Council

The public council has two stateless modes: local TinyLLM through Ollama, and a free-model OpenRouter relay. Free-tier queues vary; the runtime falls through its verified free roster and stops honestly if every free model is unavailable. It does not switch to a paid model.

Open Dashboard data

Catalogue coverage, free-plan quotas, prices, source health, and app/model relationships are separate views. An unavailable source should stay visible as unavailable instead of being coerced into a zero or an empty success.

The Drop

The Drop is a standalone platform. The Forest handoff opens https://thedrop.sdforest.site in a separate tab. Its old Vercel host can return an authentication response by design; use the custom domain for the public publication.

What to include when reporting a failure

  1. Copy the exact route and whether it opened in the same page or a new tab.
  2. Record the visible state: loading, unavailable, empty result, authentication boundary, or a server status.
  3. Keep the source date or source link shown by the page. Do not substitute a guessed “latest” value.
  4. Say whether the problem is in the Forest shell, a public companion, or an external service. Those are different owners.
