AI-d kit

About this pool

Tools for choosing, pricing and debugging AI models, built while running a fleet of agents. All of it is free and none of it needs an account.

Open Dashboard MCP

Ask your agent which model to use and what it will cost, and get an answer built from live provider catalogues. It is read-only. A missing key or a blocked provider comes back as exactly that, never as an empty or free result.

Add it to Claude Code:

claude mcp add open-dashboard -- npx -y open-dashboard-mcp

Search first, then read

The unified search and glossary are the main way in. Mapping a blocker to a tool is a guided mode inside the pool, not a gate in front of it.

  • LibraryAI terms, platforms, tools and research collections in one searchable index, glossary included.
  • Explore ReposEvery public repository on the fleet's GitHub account, originals and reference forks, searchable in one place.
  • Repo Shelf (external site)1,192 repositories, originals and forks, as books on a 3D shelf to browse rather than search.
  • The Drop (external site)A daily AI publication. Today's pick first, then what still matters from earlier drops.
  • Model councilsPut one question to a panel of free models. Public and stateless: nothing you ask is remembered.

In development

Built and under review, not public yet. These get links when they ship.

Model Router
An OpenAI-compatible proxy that picks the model for each request with a typed, readable decision, or refuses.
Glass PR Solver
Drains a pull-request backlog through four independent stages, with every fact and decision visible.
Glass Council
A private model council you install yourself, on Windows, Android or as an MCP server.
System One Bench
Measures per-decision latency and cost of typed decision models on your own machine, and says UNAVAILABLE rather than comparing when a provider is missing.
