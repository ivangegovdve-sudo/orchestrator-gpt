The redundancy calls

The map is intentionally opinionated: one source of truth, a provenance layer, one structured retrieval sidecar, and only the adjuncts that solve a different problem.

Canonical filesChoose one of AI-Context-OS, Obsidian-Mind, or Knowledge Engine. The rest of the vault/wiki cluster is redundant as a second source of truth.
CaptureKeep Agent Beacon alongside the canonical layer for cross-harness traces and replay; it is not the observation database.
Structured recallTest one of Agentmemory, MemPalace, Mnemosyne, or RetainDB Local. Running all four duplicates the same sidecar role.
AdjunctsQMD for file search, one code graph, one context-window manager, and screenshot-memory only when those modalities are actually needed.

Fleet handoff

No candidate has been tested against the existing 585,199 observations from this machine. Before any replacement decision, measure bulk import, incremental append, lexical-only recall with inference disabled, local-model cost, restart/recovery, duplicate handling, and human edits.

The page renders the research map; it does not connect to a database, call an API, or claim that a candidate runs.
