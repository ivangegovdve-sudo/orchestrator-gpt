# Weekly AI/ML Glossary Terms (2026-09-28)

## Retrieval-Augmented Generation (RAG)

Definition: Retrieval-Augmented Generation is an AI technique that retrieves relevant information from external sources before generating a response.

Explanation: RAG helps language models provide more accurate and up-to-date answers by grounding their outputs in retrieved documents. It can also reduce hallucinations because the model has supporting context beyond its training data.

## Low-Rank Adaptation (LoRA)

Definition: Low-Rank Adaptation is a parameter-efficient method for fine-tuning large neural networks by training small low-rank update matrices instead of modifying all model parameters.

Explanation: LoRA reduces the memory and computing resources required to adapt a model to a specific task or domain. The resulting adapters can be stored separately and applied to the original model when needed.

## Reinforcement Learning from Human Feedback (RLHF)

Definition: Reinforcement Learning from Human Feedback is a training approach that uses human preferences to guide a model toward more useful, safe, and aligned behavior.

Explanation: Humans compare or rank model outputs, and those preferences are used to train a reward model. The language model is then optimized to produce responses that receive higher predicted human approval.
