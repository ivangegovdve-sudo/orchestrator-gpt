# Weekly AI/ML Glossary Terms (2026-08-17)

## Retrieval-Augmented Generation (RAG)

Definition: Retrieval-Augmented Generation is a technique that supplies a generative AI model with relevant information retrieved from an external knowledge source.

Explanation: The model uses the retrieved material as context when producing its response. This can improve factual accuracy, incorporate current or private information, and reduce hallucinations.

## Mixture of Experts (MoE)

Definition: Mixture of Experts is a neural-network architecture that routes each input to a selected subset of specialized model components called experts.

Explanation: Activating only some experts for each input allows the model to have many parameters without using all of them for every computation. This can increase model capacity while keeping inference costs comparatively manageable.

## Knowledge Distillation

Definition: Knowledge distillation is a training method in which a smaller student model learns to reproduce the behavior of a larger teacher model.

Explanation: The student typically learns from the teacher’s probability distributions or generated outputs rather than relying only on original labels. The goal is to retain much of the teacher’s performance in a model that is faster and less expensive to run.
