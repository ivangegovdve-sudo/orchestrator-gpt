# Weekly AI/ML Glossary Terms (2026-08-31)

## Retrieval-Augmented Generation (RAG)

Definition: RAG is a technique that retrieves relevant information from external sources before generating an answer.

Explanation: It helps language models use current, domain-specific, or private data without retraining the model. The retrieved content can also make responses more accurate and easier to verify.

## Low-Rank Adaptation (LoRA)

Definition: LoRA is a parameter-efficient fine-tuning method that trains small low-rank matrices instead of modifying all model parameters.

Explanation: This greatly reduces the memory and computational resources required to adapt a model to a specific task. The resulting adapter can be stored separately and applied to the original model when needed.

## Mixture of Experts (MoE)

Definition: MoE is a neural-network architecture that routes each input to a subset of specialized expert networks.

Explanation: Because only some experts are activated for each input, an MoE model can have many parameters while using less computation per token. A routing mechanism determines which experts are best suited to process each part of the input.
