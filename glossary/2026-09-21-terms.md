# Weekly AI/ML Glossary Terms (2026-09-21)

## Retrieval-Augmented Generation (RAG)

Definition: RAG is a technique that retrieves relevant information from external sources and provides it to a language model as context for generating an answer.

Explanation: It helps models produce more accurate and up-to-date responses without requiring retraining for every new piece of information. A typical RAG system combines document search, context assembly, and language-model generation.

## Low-Rank Adaptation (LoRA)

Definition: LoRA is a parameter-efficient fine-tuning method that trains small low-rank matrices instead of modifying all the parameters of a pretrained model.

Explanation: This significantly reduces the memory and computational requirements of adapting a model to a new task or domain. The learned adapters can also be stored separately and attached to the base model when needed.

## Quantization

Definition: Quantization is the process of representing model weights or activations with lower-precision numerical formats to reduce memory usage and accelerate inference.

Explanation: For example, a model may use 8-bit or 4-bit values instead of 16-bit or 32-bit floating-point numbers. Lower precision can improve efficiency, though excessive quantization may reduce model accuracy.
