## 2024-05-24 - Interactive Elements Missing Focus Outlines
**Learning:** Vanilla JS sub-projects in this repository often use custom styled buttons, inputs, selects, and textareas with explicit `outline: none;` without providing a fallback `:focus-visible` state. This completely breaks keyboard navigation visibility for users relying on Tab navigation. Additionally, clickable parent elements like `.chip` that wrap hidden/styled checkboxes need focus styles passed up via the `:has()` selector (e.g., `.chip:has(input:focus-visible)`) since the visually hidden input receives the actual DOM focus.
**Action:** When working on vanilla HTML/JS projects in `web/`, always ensure `button`, `input`, `textarea`, and `select` have explicit `:focus-visible` styles (e.g., using a ring or outline using the primary accent color) to maintain accessibility.
