## 2025-02-25 - Item Icon Generator XSS
**Vulnerability:** XSS vulnerability in `frontend/index.html` where `taskUUID` and `imageURL` from backend responses were directly interpolated into `innerHTML` strings without HTML escaping or URI sanitization.
**Learning:** Even though the frontend receives data from a "trusted" backend API, the backend data originates from an external third-party API (Runware) or user input, making it potentially malicious. It's a surprising architectural gap because XSS mitigation was present in other sub-projects (`web/ai-init/`, `web/llm-db/`), but entirely missing in the root `frontend/index.html` application.
**Prevention:** Vanilla JS applications in the `frontend/` directory (like the `web/` directory) that use `innerHTML` must always implement and apply HTML sanitization functions (like `escapeHtml`) and validate URL protocols (like `sanitizeUrl` restricting to `http/https`) to prevent XSS and `javascript:` URI execution.
